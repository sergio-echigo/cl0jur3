# Leiningen
Learning about the [leiningen](http://leiningen.org/), a very useful tool for creating and managing clojure projects; some of its functionalities are dependency resolving and the read-evaluate-print-loop -- *REPL*.

## Basic steps 
```bash
# Creating a new clojure application:
lein new app <APP_NAME>

# Running it:
lein run

# Generating an executable java file:
lein uberjar
```

## Running the REPL
```bash
lein repl
```
